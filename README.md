## 🌟 نظرة عامة | Overview

**مختبر أوامر الذكاء الاصطناعي (AI Prompt Lab)** هو استوديو متكامل يجمع بين قوة **هندسة الأوامر (Prompt Engineering)** والواجهات التفاعلية المرنة (CLI-Style Command Studio & Live Builder). 

يقدم التطبيق مكتبة ضخمة ومنظمة من الأوامر الاحترافية الموزعة على مسارات تخصصية دقيقة (التعليم والجرائد المدرسية، تطوير البرمجيات، الحملات الإعلانية والتسويقية، صناعة الفيديو وShorts، السيرة الذاتية والمسار المهني، وتوليد الصور والتصميم البصري)، مع محرر تفاعلي حي يتيح تخصيص المعاملات والرايات (`Flags & Parameters`) ونسخ الأوامر المصاغة بدقة فائقة.

---

## ✨ الميزات الرئيسية | Key Features

### 1. 🗂️ المكتبة التخصصية المتكاملة (Domain Libraries)
- **🎓 المسار التعليمي (Education & Lesson Newspaper)**:
  - تحويل أي درس إلى **جريدة تعليمية إنفوجرافيك قابلة للطباعة A4** (`/lesson newspaper`).
  - توليد أنشطة تفاعلية: كلمات متقاطعة (`/lesson crossword`)، متاهات (`/lesson maze`)، وشبكات البحث عن الكلمات (`/lesson word search`).
  - أوراق عمل تدريبية وبوسترات تعليمية ملخصة للدروس.
- **💻 هندسة البرمجيات والتطوير (Software Engineering & Dev)**:
  - أوامر معيارية لتصميم المعماريات (`Architecture`)، تصحيح الأخطاء (`Debugging`)، مراجعة الأمان والـ Code Review، وهندسة الـ DevOps.
- **📢 الإعلانات والتسويق الرقمي (Ads & Marketing)**:
  - استراتيجيات الحملات الإعلانية على Meta وGoogle Ads وTikTok وLinkedIn.
  - صياغة نصوص إعلانية موجهة وفق صيغ AIDA وPAS والتحليل المتقدم للأداء.
- **🎨 التصميم البصري وتوليد الصور (Visual Design & AI Art)**:
  - معادلات الأوامر البصرية المتكاملة للمنتجات، البورتريه، الهويات التجارية، والعمارة.
- **🎬 صناعة الفيديو والمحتوى القصير (Video & Shorts/Reels)**:
  - كتابة السيناريوهات، جداول المشاهد (Shot Lists)، وهندسة خطافات المشاهدة (Hooks).
- **📄 السيرة الذاتية والتطوير المهني (Career & CV Crafting)**:
  - تهيئة السيرة الذاتية لتجاوز أنظمة الـ ATS والتحضير لمقابلات العمل التقنية والإدارية.

### 2. ⚡ محرر وباني الأوامر التفاعلي (Interactive Command Builder & Playground)
- **محرر بصري تفاعلي**: ملء وتعديل المعاملات الموضعية والاختيارية في الوقت الفعلي مع تحديث فوري للأمر.
- **معاينة حية ومباشرة**: بناء الجملة بدقة `CLI Syntax` مع إمكانية النسخ الفوري بنقرة زر.
- **سجل الأوامر (History)**: حفظ الأوامر المنشأة والرجوع إليها في أي وقت محلياً.

### 3. 🗺️ المسارات الإرشادية الموجهة (Guided Workflows)
- سيناريوهات متكاملة خطوة بخطوة تقود المستخدم من مرحلة التخطيط وحتى الناتج النهائي المتكامل.

### 4. 🌐 واجهة ثنائية اللغة وتصميم فائق الأداء (Bilingual & Responsive)
- دعم كامل للغتين العربية والإنجليزية مع مراعاة كاملة لاتجاه الخطوط (`RTL/LTR`).
- تصميم حديث مبني بأحدث معايير **Tailwind CSS v4** ودعم الوضعين الليلي والنهاري (Dark / Light Mode).

## 📐 معمارية الأوامر المعيارية | Prompt Architecture

تعتمد المنصة صيغة قياسية موحدة للأوامر تُشبه واجهات سطر الأوامر (CLI):

```bash
/namespace subaction [Positional_Value] --flag1=value --flag2=value --instruction="Master Guidance"
```

### 💡 مثال عملي (Practical Example):

```bash
/lesson newspaper دورة الماء في الطبيعة \
  --subject=العلوم \
  --level=الصف_الرابع_الابتدائي \
  --games=crossword,maze,word-search \
  --language=ar \
  --format=educational-newspaper-infographic \
  --print-ready=yes \
  --instruction="صمم الناتج كإنفوجرافيك لجريدة تعليمية حقيقية قابلة للطباعة، بتخطيط أعمدة وعناوين وصناديق وأنشطة بصرية."
```

## 🚀 دليل التثبيت والتشغيل | Quick Start

### المتطلبات الأساسية (Prerequisites)
- [Node.js](https://nodejs.org/) الإصدار 18 أو أحدث
- مدير الحزم `npm` أو `yarn` أو `pnpm`

### 1. الاستنساخ والتثبيت (Clone & Install)
```bash
# استنساخ المستودع
git clone https://github.com/your-username/interactive-prompt-lab.git

# الدخول إلى مجلد المشروع
cd interactive-prompt-lab

# تثبيت الحزم البرمجية
npm install
```

### 2. تشغيل بيئة التطوير المحلية (Local Dev)
```bash
npm run dev
```
افتح المتصفح على: `http://localhost:3000`

### 3. بناء النسخة الإنتاجية (Production Build)
```bash
npm run build
```

## ☁️ دليل النشر السحابي | Deployment Guide

### أ) النشر على Cloudflare Pages (الموصى به مجاناً):
1. اربط مستودع GitHub الخاص بك في [Cloudflare Dashboard](https://dash.cloudflare.com/).
2. اختر **Pages** > **Create Application** > **Connect to Git**.
3. اضبط إعدادات البناء:
   - **Framework Preset**: `Vite`
   - **Build Command**: `npm run build`
   - **Output Directory**: `dist`
4. اضغط **Save and Deploy** (ملف `public/_redirects` مدمج بالفعل لضمان دعم مسارات SPA).

### ب) النشر على Vercel:
1. استورد المستودع في [Vercel Dashboard](https://vercel.com/).
2. سيقوم Vercel باكتشاف إعدادات Vite تلقائياً، اضغط **Deploy**.
